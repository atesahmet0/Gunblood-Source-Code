# Extracted and recovered Flash resources

The `export/` tree is the original FFDec 26.3 extraction, including its initial gameplay script. The improved, readable gameplay unit is `recovered/gameplay.as`; see `recovered/RECOVERY.md` for the exact scope of recovery and validation. Original bytecode listings are in `pcode/`.

The archived input and derived validation SWF are preserved separately. The 1,392 sprite SVGs and 208 button SVGs are exported frames/states, not distinct complete character models or executable animations.

The rejected experiment exports, raw failed passes, bundled tool binaries, website mirrors, and duplicate ZIP downloads are excluded from this repository. `recovery-legacy/` retains only the one FFDec 18.5 gameplay unit needed by the recovery script. Sanitized recovery/compile logs are in `logs/`.
